#Web Pricing and Standards

## Estándares generales
* Mobile First y Diseño Responsivo
* Páginas ligeras de carga rápida y recursos optimizados (Lighthouse Performance 90+)
* SEO básico y Semántica (Título, Descripción, OpenGraph, sitemap y robots.txt básicos)
* Accesibilidad (a11y): Contrastes adecuados y textos alternativos.
* Stack escalable (Astro/Next.js)
* Documento con resumen técnico del proyecto (Stack, estructura, despliegue)

## Tier 1 - Landing Page | 1 página
### 120 - 180 mil pesos chilenos
1. Hero
2. Menú
3. Ubicación / Horario
4. Contacto / WhatsApp

* Animaciones: Hover botones y links, Fade-in básico.
* Personalización: Paleta de colores de acuerdo a la marca, Tipografía a elección, layout a elección.

## Tier 2 - Sitio estándar (Sin CMS) | 3 - 5 páginas
### 280 - 420 mil pesos chilenos
1. Home
2. Menú
3. Galería
4. Sobre Nosotros
5. Contacto / Ubicación / Horarios

* Animaciones: Anterior + Scroll reveal, animaciones para galería, botones.
* Personalización: Paleta de colores de acuerdo a la marca, Tipografía a elección, layout a elección.

## Tier 3 - Sitio estándar + Secciones con CMS | 3 - 5 páginas
### 550 - 900 mil pesos chilenos
1. Home
2. Menú + CMS
3. Galería + CMS
4. Sobre Nosotros
5. Contacto / Ubicación / Horarios
6. Blog / Noticia / Actualizaciones, etc. + CMS

* Animaciones: Todo lo anterior, pero aplicado a componentes dinámicos.
* Personalización: Paleta de colores de acuerdo a la marca, Tipografía a elección, layout a elección.


## Incluye
* Creación de correo Gmail para la página
* Creación del Github para el repositorio
* Creación de cuenta en Cloudflare Pages
* Indexación al buscador de Google
* Puesto en producción
* Capacitación por videollamada
* QR Personalizado con el logo

## Pago mensuel incluye
### Primer mes gratis
* 2 horas de cambios en el código (textos, imágenes)
* Monitoreo de Uptime (UptimeRobot), aviso por WhatsApp / Email respecto a caídas del sitio
* Analítica Básica (Google Analytics), aviso mensual por WhatsApp / Email con resumen de visitas a sitio o por botones.
* Aviso anticipado del vencimiento del dominio para renovación

## Restricciones
* El nombre del dominio corre por cuenta del cliente
* No hago fotografías
* No hago logos
* No hago redacto la sección "Quiénes Somos"
* No hago backend (Pasarelas de pago, Bases de Datos, Sistemas de inventario..)
    * Shopify a evaluar si se necesita vender (Aumenta el valor)
